3. Подготовьте ключ и запрос на самом узле

  1. Выполните agp-agent-identity keygen в приватном каталоге 0700. Приватный ключ остаётся на узле.
  2. Запустите agp-agent-identity request с доверенными CA и привязкой к выбранному Node ID. Передайте одноразовый токен через stdin или защищённый файл.
  3. Откройте запрос ниже. Сверьте publicKeyDigest непосредственно с выводом CLI на узле, введите отпечаток вручную и подтвердите.
  4. После approval выполните agp-agent-identity enroll на том же узле. Затем запустите агент для отправки инвентаризации и обновите список наблюдений.
